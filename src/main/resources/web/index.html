Configurações

Padrões
Vercel CLI

Use se a CLI foi instalada fora do PATH. O app nunca lê o login da CLI.

Atualização automática
Servidor

O servidor escuta só em 127.0.0.1. Mudar a porta exige reiniciar.

Histórico local

Chega na próxima fase. Nada é gravado em disco além de config.json e dos logs.

Limitações por plano
  • Edge Requests exigem Observability Plus e não aparecem no painel.
  • Bounce rate não está disponível pela CLI.
Encerrar

Fecha o servidor local. Para abrir de novo, rode o Overlook outra vez.
